- 玻璃背景透明度可在 10%–80% 间调节，文字保持清晰；选择、透明度、语言和配色会保存。
- 保留头像上方标记、全年统一热力图色阶、玻璃悬停详情及原有更新流程。
- 主面板与图表接入真实可得数据；缺失 Token、逐任务用量和不可比的小时速率不以演示数字填充。

主面板是原生绘制的玻璃外观，右下角浮窗使用逐像素透明背景，不捕获桌面图像。系统托盘本身的大小仍由 Windows 决定，选择卡片或胶囊可获得更大的显示和点击区域。
