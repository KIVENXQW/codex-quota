Codex 额度工具 2.2.0

打开：双击本目录的 CodexQuota.exe，或在 Codex 中使用“Codex 额度面板”本地插件。
重复打开不会产生多个实例，会显示已有实例的详情窗口。

Codex 左下角头像上方：显示剩余额度。点击打开详情。
窗口最小化或头像被遮挡时，头像标记隐藏；只切到其他应用、Codex 头像仍可见时保持显示。
Windows 系统托盘：数字表示剩余百分比。悬停显示额度和重置时间，点击打开详情。
如果 Windows 将图标折叠，点击任务栏右下角的向上箭头查找数字图标。
右键托盘图标可立即刷新、切换头像标记或退出工具。

每 60 秒自动读取账户数据，不调用模型。缺失数据不会显示成 0。
灰色标记或感叹号表示数据暂不可用或正在显示缓存，请点击刷新。
多个额度窗口同时存在时，小图标显示剩余最少的一项，详情显示全部窗口。
重置时间使用北京时间。积分余额与套餐额度分别统计。

2.2 玻璃面板
首页显示核心用量与额度；历史统计包含趋势、分段大热力图和累计记录。
日：最近7天；周：最近4周（周一开始）；月：最近6个自然月。
切换 Tokens / 时长查看柱状图。悬停柱子显示精确数值、任务次数和覆盖情况，也可用方向键查看明细。
累计区集中展示账户累计Token、单日峰值、本机已记录工作时长/任务数、最长任务及连续使用天数。

“外观”提供中文/English、预设颜色和圆角HSV调色面板，也可输入十六进制色值。
语言和颜色自动保存至本机 .data/native-preferences.json，并同步头像标记和托盘。
字体固定采用接近Codex侧栏的系统UI风格，不提供字体下拉选择。打开时有短暂淡入与位移动画。

数据口径
Token来自账户接口的每日记录，可能延迟，今天缺失不会显示为零。
工作时长和完成任务来自本机Codex元数据；按最近90天范围采集，不读取消息正文。
从每次提交到结束计算时长，排除回合间空闲，并把并发区间合并。尚未结束的任务完成后才纳入。
本机历史不代表当前账户全部设备的数据。星号/“部分”表示旧记录缺失或未覆盖完整时段。
热力图空心格表示没有记录。费用及输入/输出/缓存Token分项没有已验证的数据源，未作推算。

检查更新
右键 Windows 托盘数字图标，选择“检查更新”。
关联 GitHub 仓库后，启动时以及运行期间按设置间隔检查稳定版，发现新版显示提示。
点击“下载并安装”才开始安装；下载、SHA256及文件校验完成后，由独立助手替换程序并重新启动。
个人统计、语言、颜色和现有更新来源配置保留；替换失败会恢复备份。
更新来源为公开仓库 KIVENXQW/codex-quota，无需访问令牌。
旧版首次升级仍显示旧更新窗口；安装后进入玻璃界面。详细发布步骤见 UPDATES.md。

该工具是跟随 Codex 的本地原生伴随程序，不修改 Codex 应用文件。
安装包的 Start-Native.ps1 包含可选登录启动设置，不会在普通启动时擅自启用。
在完整解压目录打开 PowerShell 后运行一次：
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Start-Native.ps1 -Startup Enable -NoLaunch
关闭时将 Enable 改为 Disable。移动解压目录后，从新目录重新启用一次。
当前电脑已有的同名 Windows 启动项会沿用；其他电脑需要自行启用。

开发验证：Build-Native.ps1
启动脚本：Start-Native.ps1
停止命令：CodexQuota.exe --quit
